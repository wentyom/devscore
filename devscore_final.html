How it works

From URL to verifiable score in minutes

No manual review. No opaque scoring. Every result is produced by independent AI consensus and anchored on-chain.

01
🔗
Submit profiles

Provide a GitHub URL, LinkedIn URL, and the target role. The review is scoped to what that position actually requires.

02
⚙️
AI fetches live data

The GenLayer intelligent contract calls gl.get_webpage() directly — no scraper, no middleman, no stale cache.

03
🧠
5 validators score independently

Each GenLayer validator runs a different LLM. All five evaluate the same profile and must reach consensus on the final scores.

04
⛓️
Results stored on-chain

The finalised score, reasoning, and recommendations are written to the contract state — permanent, verifiable, tamper-proof.

Scoring criteria

Six dimensions, one honest number

Every aspect of a developer's public profile is assessed relative to the target position — not against a generic rubric.

💻
Technical Skills
Languages, frameworks, and tools evident from GitHub activity. Depth over breadth — specialisation in the right stack is rewarded.
WEIGHT: HIGH
📁
Project Quality
README completeness, commit consistency, code architecture, test coverage signals. Poor docs score low regardless of star count.
WEIGHT: HIGH
🏢
Experience
Total tenure, career progression, company calibre, and relevance of past roles to the position being evaluated.
WEIGHT: MEDIUM–HIGH
✍️
Communication
Clarity of bio and profile description, ability to explain technical work in plain language, LinkedIn summary quality.
WEIGHT: MEDIUM
🎯
Position Fit
How closely the candidate's demonstrated skills and experience map to the specific role provided. The most contextual of all criteria.
WEIGHT: HIGH
⭐
Overall Score
A weighted composite of all five criteria, normalised to 0–100. Maps to a level: Junior, Mid, Senior, or Lead.

Why it's trustworthy

Not one AI. Five independent verdicts.

GenLayer's Optimistic Democracy mechanism routes the same evaluation to five validators, each running a different language model. Consensus is required before any score is accepted. A single biased model cannot influence the outcome.
